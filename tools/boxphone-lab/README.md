# Boxphone Lab — โปรแกรมทดลอง

อัปเดตรุ่น 2: อ่าน [GUIDE-v2.md](GUIDE-v2.md) สำหรับข้อความแยกเครื่อง การฟังต่อเนื่อง และพอร์ตใหม่ 8766 ข้อมูลด้านล่างเป็นคู่มือรุ่นแรกและไม่สะท้อนฟังก์ชันส่งจริงที่เพิ่มภายหลัง

เปิด Start.cmd แล้วเข้า http://127.0.0.1:8765 โปรแกรมทำงานเฉพาะบนคอมพิวเตอร์นี้ ใช้ Node.js 22+ และ ADB ของ Xiaowei โดยไม่ต้องติดตั้งแพ็กเกจเพิ่ม

## ทดลองโดยไม่ใช้ AI

1. กดค้นหาเครื่อง แล้วเลือกเครื่อง หรือเลือกทั้งหมด
2. กด “ดูจอ” เพื่อตรวจภาพจริงจากมือถือ (ไม่แตะหน้าจอ)
3. กด “ข้อความตัวอย่าง” และ “ตัวอย่างคำถาม” ข้อความเหล่านี้ตายตัว ไม่ใช่ผลจาก AI
4. กด “เข้าคิวจำลอง” แล้ว “เริ่มจำลอง”
5. บันทึกผล JSON ได้ คิวและคีย์ไม่ถูกบันทึกอัตโนมัติ

## ทดลอง AI จริง

ใส่ OpenAI API key ในช่องบนหน้าจอ ไม่ต้องส่งคีย์ในแชต ระบบเก็บคีย์เฉพาะหน่วยความจำและส่งให้บริการ OpenAI เมื่อกดปุ่ม API คีย์หายเมื่อรีเฟรชหน้า (โปรแกรมไม่ใช้ localStorage)

เลือกไฟล์เสียงไม่เกิน 24 MB หรืออัดเสียงไมโครโฟน/แท็บ แล้วกดถอดเสียง จากนั้นตรวจบทพูดและกดสร้างคำถาม การเรียก API มีค่าใช้จ่ายตามบัญชีและต้องมีเครดิต

เสียงแท็บ/หน้าจอ: ใช้ Chrome หรือ Edge เลือกแหล่งเสียงแล้วเปิดแชร์เสียง ถ้าเบราว์เซอร์ในแอปไม่รองรับ ให้อัปโหลดไฟล์หรือเปิด URL ใน Chrome/Edge การอัดหยุดใน 60 วินาทีและถอดเสียงหลังจบ ไม่ใช่การฟังสตรีมต่อเนื่อง

โมเดล: gpt-4o-mini-transcribe สำหรับถอดเสียงภาษาไทย และ gpt-4o-mini ผ่าน Responses API สำหรับคำถาม ผลลัพธ์กรองข้อความซ้ำแบบตรงตัว เก็บประวัติคำถาม 20 รายการในหน้านี้

## โหมดส่งจริง (Live Mode — TikTok Live)

โปรแกรมมีสวิตช์สลับระหว่าง **โหมดทดลอง (Dry-run)** และ **โหมดส่งจริง (Live Mode)** ที่มุมขวาบนของหน้าจอ

### ข้อกำหนดก่อนส่งจริง
1. **ติดตั้ง ADBKeyBoard**: บนมือถือแต่ละเครื่องต้องติดตั้ง [ADBKeyBoard](https://github.com/senzhk/ADBKeyBoard) APK เพื่อให้สามารถส่งข้อความภาษาไทยและ Unicode ผ่าน ADB ได้ (ระบบรองรับการกด "ตรวจสอบ ADBKeyBoard" และ "ตั้งเป็น keyboard หลัก" ผ่านหน้าเว็บ)
2. **เปิด TikTok เข้าห้องไลฟ์**: เปิดแอป TikTok บนมือถือและเข้าไปยังห้องไลฟ์ที่ต้องการส่งคอมเมนต์ให้พร้อม
3. **ตั้งค่าพิกัดหน้าจอ (Coordinates)**:
   - **พิกัดช่องแชท (Chat X, Y)**: จุดที่แตะเพื่อเปิดแป้นพิมพ์
   - **พิกัดปุ่มส่ง (Send X, Y)**: จุดที่แตะเพื่อกดส่งคอมเมนต์
   - สามารถใช้ปุ่ม **"📐 คำนวณอัตโนมัติ"** (อิงตามขนาดหน้าจอ) หรือกด **"📍 จับพิกัดจากภาพหน้าจอ"** แล้วคลิกเลือกจุดบนภาพหน้าจอมือถือจริงได้

### การทำงานขณะส่งจริง
- เมื่อกด **"🚀 เริ่มส่งจริง"** โปรแกรมจะส่งคำสั่ง ADB ไปยังมือถือ: แตะช่องแชท → ส่งข้อความผ่าน ADBKeyBoard broadcast → แตะปุ่มส่ง
- มีการหน่วงเวลาแบบสุ่ม (jitter ±20%) และจำกัดความถี่ขั้นต่ำ 3 วินาทีต่อเครื่อง เพื่อความปลอดภัย

> ⚠️ **คำเตือนความเสี่ยงบัญชี**: การใช้ระบบอัตโนมัติส่งคอมเมนต์ใน TikTok Live มีความเสี่ยงที่จะถูก TikTok ตรวจจับว่าเป็นพฤติกรรมบอท และอาจทำให้บัญชีถูกจำกัดการคอมเมนต์หรือระงับการใช้งาน ควรตั้งช่วงเวลาการส่งไม่ให้ถี่เกินไปและใช้ด้วยความระมัดระวัง

## ขอบเขตและโครงสร้างโปรแกรม

- โหมดทดลอง: จัดคิวและจำลองผลลัพธ์บนเครื่องคอมพิวเตอร์เท่านั้น ไม่มีการสั่งแตะหรือพิมพ์บนมือถือ
- โหมดส่งจริง: ส่งคำสั่งแตะและพิมพ์ข้อความผ่าน ADB ไปยังมือถือที่เลือก
- คิวมีอายุ 2 นาทีจากเวลาสร้างคำถาม และจำกัด 500 รายการ การกดหยุดจะหยุดคิวชั่วคราว
- บันทึกผลลัพธ์เป็นไฟล์ JSON ได้ผ่านปุ่ม "บันทึกผล JSON"

โครงสร้าง: `server.mjs` คือบริการ ADB/API, `index.html` และ `app.js` คือหน้าจอโปรแกรม
เปลี่ยนตำแหน่ง ADB ด้วย `BOXPHONE_ADB` และพอร์ตด้วย `PORT` ก่อนเปิด `server.mjs` โดยตรง
โปรแกรมจำกัดการเข้าถึงเฉพาะ `127.0.0.1` ไม่ควรเปิดบริการนี้ให้เข้าถึงจากเครือข่ายภายนอก

อ้างอิง: https://developer.android.com/tools/adb และ https://github.com/senzhk/ADBKeyBoard
