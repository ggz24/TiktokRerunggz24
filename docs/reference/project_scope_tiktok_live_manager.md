# คำสั่งสำหรับ ChatGPT
คุณคือ Project Manager ของโปรเจคนี้ ใช้สโคปด้านล่างเพื่อ:
1. ถามฉันก่อน: วันเริ่มโปรเจค, วันทำงาน (จันทร์–ศุกร์ หรือทุกวัน), ชั่วโมงทำงานต่อวันของแต่ละคน, วันหยุด
2. แบ่งงานรายวันให้แต่ละคนตาม Task ID โดยเคารพ "ขึ้นกับ (Depends on)" และค่าประมาณ (วันทำงาน)
3. ทำตารางรายวัน: วันที่ | คน | Task ID | สิ่งที่ต้องส่งวันนั้น (Deliverable)
4. ทุกวันเมื่อฉันรายงานความคืบหน้า ให้ปรับแผนใหม่ แจ้งงานที่ล่าช้า และงานที่ติด dependency
5. ใช้ Definition of Done ของแต่ละ Task ในการรับงาน

# โปรเจค: TIKTOK LIVE MANAGER (พัฒนาเอง)

## 1. ภาพรวม
เว็บแอปจัดการไลฟ์ขายของ TikTok แบบอัตโนมัติ หลายบัญชีพร้อมกัน:
- ส่งคลิป .mp4 จากคลังขึ้นไลฟ์ ตั้งเวลาขึ้น/ลงไลฟ์ วนไลฟ์ กู้สตรีมเมื่อหลุด
- ดึงสถิติ TikTok Shop (GMV, ขายได้, ผู้ชม, เข้าชม, แสดงผล) + จัดการสินค้าในไลฟ์
- รับคอมเมนต์เรียลไทม์ ตอบอัตโนมัติด้วยกฎคำ ทักคนเข้าห้อง และ AI ช่วยตอบ
- ระบบผู้ใช้/ไลเซนส์, แดชบอร์ด, หน้าตั้งค่า 7 แท็บ

## 2. ทีมและบทบาท
| คน | บทบาท | พื้นฐาน |
|---|---|---|
| น็อต | Streaming Engine + Automation Scheduler (Tech lead ฝั่ง backend) | n8n automation, เว็บไซต์ |
| โอ๊ต | Core Platform + Frontend/Dashboard | เว็บเช็คอินออนไลน์ |
| ซี | Stats / Sales / Products | เว็บคำนวณคอมมิชชั่น |
| ภูมิ | Comments / Auto-reply / AI | โปรแกรมตอบกลับไลฟ์อัตโนมัติ |

## 3. เทคโนโลยี (ตกลงร่วมกัน)
- Backend: Node.js + TypeScript (Fastify/Express), Worker แยก process
- DB: PostgreSQL (Prisma), Queue/Cache: Redis + BullMQ
- Frontend: React/Next.js + Tailwind, Realtime: WebSocket (Socket.IO)
- Streaming: FFmpeg (`-re -c copy` ส่ง RTMP)
- Deploy: Docker Compose บน VPS, Git (GitHub) + branch ต่อคน + Pull Request
- แจ้งเตือน: n8n → LINE/Telegram

## 4. ข้อตกลงกลาง (Shared Contracts) — ต้องเสร็จก่อนเริ่มงานแยก
Event bus (Redis pub/sub):
- `live.starting`, `live.started {accountId, roomId, streamStartedAt}`, `live.stopped {accountId, reason}`, `live.error`
- `stats.updated {accountId, gmv, sold, viewers, enters, impressions, gmvPerHour, impressionsPerHour}`
- `comment.received {accountId, user, text, type: comment|enter|like|gift}`
- `chat.send.request {accountId, text}` / `chat.sent` / `chat.failed`
Data model หลัก: User, License, Account(TikTok), AccountSettings, Video, Playlist, ProductSet, LiveSession, StatsSnapshot, ReplyRule, GreetingConfig, AiConfig, AiLog, CommentLog

## 6. สรุปภาระงานรวม (ประมาณ)
- น็อต: ~27.5 วันทำงาน (รวม Phase 0/2)

- ซี: ~21.5 วัน

## 7. Milestones
- M1 (สิ้นสัปดาห์ 1): Phase 0 เสร็จ, ล็อกอิน + เพิ่มบัญชีได้
- M2 (สัปดาห์ 3): ขึ้นไลฟ์ด้วยคลิปได้จริง, ดึงยอดได้, รับคอมเมนต์ได้
- M3 (สัปดาห์ 5): Automation ครบ, สินค้า, กฎตอบ + AI ครบ
- M4 (สัปดาห์ 6–7): Integration, QA, Deploy, ส่งมอบ
