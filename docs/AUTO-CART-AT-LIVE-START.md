# เพิ่มชุดสินค้าเข้าตะกร้าอัตโนมัติตอนเริ่มไลฟ์

ในหน้า LIVE ของแต่ละบัญชี ชุดสินค้าที่บันทึกไว้จะมีปุ่ม **เพิ่มตะกร้าอัตโนมัติตอนเริ่มไลฟ์: เปิด/ปิด**

- เปิดแล้ว ระบบจะส่งชุดนั้นเข้าตะกร้าให้เองเมื่อบัญชีนี้เริ่ม LIVE (ใช้คำขอ cURL เดิมที่บันทึกไว้)
- เลือกเปิดได้ 1 ชุดต่อบัญชี การเปิดชุดใหม่จะปิดชุดเดิมของบัญชีเดียวกันให้เอง
- ต้องผูกชุดกับบัญชี LIVE ก่อน ชุดที่ใช้ Cookie ใน cURL อย่างเดียวเปิดไม่ได้
- ปุ่มนี้แค่ตั้งค่า ไม่ส่งอะไรไป TikTok จนกว่าจะเริ่ม LIVE ส่วนปุ่ม “ส่งเข้า LIVE” ยังส่งทันทีและตั้งชุดนั้นเป็นค่าเริ่มต้นเหมือนเดิม
- ถ้า cURL หมดอายุ TikTok จะปฏิเสธตอนเริ่ม LIVE ให้คัดลอกคำขอใหม่แล้วแก้ไขชุดสินค้า

API: `POST /api/v1/live/product-sets/:id/auto` ด้วย `{ "enabled": true | false }`
