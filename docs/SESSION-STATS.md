# ยอดขายและสถิติด้วย session

หน้า `/sales` ดึงตัวเลขจากหน้าสถิติของ TikTok ด้วย session ของบัญชีที่เชื่อมไว้ ไม่ต้องใช้ Open API ทางการและไม่ต้องสมัครเป็นผู้ขาย

## วิธีใช้

1. เปิดหน้าสถิติที่ต้องการใน Chrome (บัญชีที่ล็อกอินอยู่) กด F12 → Network → โหลดหน้าใหม่ → หาคำขอที่ตอบเป็นตัวเลข (กรอง Fetch/XHR)
2. คลิกขวาที่คำขอ → Copy → Copy as cURL (bash)
3. ที่ `/sales` ตั้งชื่อ เลือกบัญชีที่ใช้ session (หรือปล่อยว่างให้ใช้ cookie ใน cURL) วาง cURL แล้วบันทึก
4. กด "ดึงข้อมูล" เมื่อไหร่ก็ได้ ระบบแสดงการ์ด GMV / ออเดอร์ / จำนวนที่ขาย / ผู้ชม / CTR / ลูกค้า เท่าที่พบในข้อมูล และมี "ข้อมูลทั้งหมดที่ TikTok ส่งมา"
5. เมื่อขึ้นว่า session หรือลายเซ็นหมดอายุ ให้คัดลอก cURL ใหม่แล้วกด "วาง cURL ใหม่"

## การทำงานและความปลอดภัย

- คำสั่งที่วางถูกอ่านเป็นข้อมูล ไม่เคยรันเป็นคำสั่งเชลล์ รับเฉพาะ `https` และโดเมน `tiktok.com`, `tiktokshop.com`, `tiktok-shops.com` ไม่รับ IP, พอร์ต หรือ user:pass
- คำขอทั้งหมด (URL ที่มีลายเซ็น, header, cookie) เก็บเข้ารหัส AES-256-GCM ผูกกับเจ้าของและรหัสแหล่งข้อมูล ไม่ส่งกลับไปที่เบราว์เซอร์ รายการแสดงแค่ชื่อโดเมน/เส้นทาง
- ส่งซ้ำตามเดิมทุกตัวอักษร (รวมช่วงวันที่และลายเซ็นใน cURL) ถ้าเลือกบัญชี ใช้ cookie ปัจจุบันของบัญชีนั้นก่อน ไม่มีจึงใช้ cookie ใน cURL ไม่ตามการเปลี่ยนเส้นทาง จำกัดผลลัพธ์ 2 MB ดึงได้ไม่เกิน 30 ครั้งต่อนาที และสูงสุด 50 แหล่งข้อมูลต่อเจ้าของ

## ข้อจำกัดที่ต้องรู้

- ไม่ใช่ API ทางการ ผลขึ้นกับว่าหน้าที่เลือกรับ session ได้หรือไม่ ลายเซ็น (`X-Bogus`, `msToken`) และ session หมดอายุได้ ระบบสร้างลายเซ็นใหม่เองไม่ได้ จึงต้องคัดลอก cURL ใหม่เป็นระยะ
- ช่วงวันที่ถูกตรึงตามที่อยู่ใน cURL เปลี่ยนวันไม่ได้โดยไม่ทำให้ลายเซ็นเสีย ถ้าต้องการช่วงอื่น ให้เก็บอีกแหล่งจากหน้าที่เลือกช่วงนั้น
- โครงสร้างตัวเลขจาก TikTok ยังไม่ได้ยืนยันกับหน้าสถิติจริง การ์ดค้นหาชื่อฟิลด์ทั่วไป (gmv, orders, viewers ฯลฯ) ถ้าไม่พบจะแสดงข้อมูลทั้งหมดแทน
