# เชื่อม AI กับแชท TikTok LIVE (เครื่องนี้)

1. เปิด Chrome โปรไฟล์ของบัญชี TikTok ที่จะไลฟ์ ไปที่ `chrome://extensions` เปิด Developer mode แล้วกด Load unpacked เลือกโฟลเดอร์นี้ (`extensions/livehub-chat`) ที่มี `manifest.json`
2. รีโหลด TikTok Shop LIVE Console หลังติดตั้ง เพื่อให้ส่วนเชื่อมเริ่มรับ WebSocket ตั้งแต่เปิดหน้า
3. เริ่มไลฟ์จาก Live Hub เปิดหน้า AI ของบัญชีนั้น กด **สร้างรหัสจับคู่**
4. กดไอคอนส่วนขยาย Live Hub Chat วางรหัสทั้งหมดและกดบันทึก
5. กลับ Live Hub กด **ตรวจการเชื่อมต่อ** เมื่อเชื่อมแล้วใส่ API key/ข้อมูลสินค้า เปิด AI ช่วยตอบแชท และบันทึก
6. ให้บัญชีผู้ชมถามคำถาม ทดสอบว่าผู้ชมเห็นคำตอบ และตรวจประวัติใน Live Hub

ต้องเปิด Chrome และ LIVE Console ค้างไว้ ใช้กับ `http://localhost:3100` เท่านั้น รหัสจับคู่หมดอายุใน 12 ชั่วโมงหรือเมื่อ API รีสตาร์ต เมื่อเปลี่ยนห้องต้องจับคู่ใหม่ ไม่มี Cookie หรือ TikTok session ถูกคัดลอกไป server

ส่วนเชื่อมให้หน้า TikTok สร้างคำขอส่งแชทเอง หากหน้า TikTok เปลี่ยน หรือไม่ยอมรับเหตุการณ์จากส่วนขยาย การส่งอาจไม่สำเร็จ ต้องตรวจห้องจริงก่อนใช้งานต่อเนื่อง ไม่มีการส่งซ้ำเมื่อผลไม่ชัดเจน ช่องพิมพ์แชทที่มีข้อความค้างอยู่จะไม่ถูกเขียนทับ

สถานะส่งแล้วหมายถึงได้รับคำตอบสำเร็จจาก TikTok ไม่ใช่การรับรองว่าผู้ชมทุกคนเห็นข้อความ ระบบหนึ่ง API replica เก็บการจับคู่ในหน่วยความจำ ไม่รองรับ server ระยะไกลในรุ่นนี้
